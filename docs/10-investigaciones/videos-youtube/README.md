# Videoteca · Análisis de vídeos de YouTube

Índice único para localizar rápidamente las investigaciones cuyo punto de partida es un vídeo de YouTube. Cada entrada identifica el vídeo, su autor o canal, la URL de acceso, la fecha de consulta y los documentos derivados.

> Incluir una entrada aquí no implica respaldar al autor ni validar automáticamente sus afirmaciones. Cada análisis debe separar contenido del vídeo, contraste externo, inferencias y recomendaciones.

## Convención para nuevas entradas

1. Crear una carpeta `videos-youtube/<autor-tema>/`.
2. Registrar como mínimo: ID `YT-AAAA-NNN`, título exacto, autor/canal, URL, fecha de consulta y enlace al análisis.
3. Mantener el informe transformativo: no copiar transcripciones completas protegidas.
4. Identificar capítulos o marcas de tiempo cuando estén disponibles.
5. Separar lo dicho por el autor de los hechos contrastados y de las recomendaciones propias.
6. Añadir la entrada a esta tabla, al [catálogo documental](../../00-biblioteca/catalogo.md) y al `CHANGELOG`.
7. No incorporar secretos, datos personales ni archivos audiovisuales sin permiso o licencia.
